Level Editor & Object Maker

Dev-only tool, excluded from the build — see game_design.md §10.

Hitbox (polygon)

Click empty space to start a new shape, click to add points, hold Shift to snap the angle. Click the first point (green) or press Enter to close it, Backspace undoes the last point, Escape cancels. Once closed: drag a point to move it (Shift snaps), double-click an edge to add a point, Alt+click a point to delete it, drag inside the shape to move it all, drag the handle above it to rotate (Shift snaps).
